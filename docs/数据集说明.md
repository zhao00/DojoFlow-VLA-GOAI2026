# 数据集说明

## 来源

训练数据为比赛提供的 GOAI/RoboDojo 官方 HDF5 数据。仓库不重新分发原始数据，只记录
来源、结构、统计和处理参数。参赛者应通过比赛官方渠道获取并遵循其授权条款。

## 已核验规模

- 12 个任务；
- 每任务 100 条轨迹；
- 1,200 条轨迹；
- 592,432 个时间步；
- 全量 HDF5 元数据检查未发现结构错误。

任务包括：

```text
arrange_largest_number
fold_clothes
hang_mugs
make_toast
pack_objects_into_box
pour_liquid_into_cup
push_T
sort_nesting_dolls_by_size
stack_blocks
stack_bowls
store_laptop_and_headphones
sweep_blocks
```

## Sample 与 trajectory

一条轨迹包含数百个时间步。数据加载器以有效时间步为锚点，将三视角图像历史、当前状态、
语言指令和未来动作 chunk 组成训练 sample。因此 1,200 条轨迹展开为 592,432 个 sample。

## 训练预处理

```yaml
num_cameras: 3
image_size: 224
img_history_size: 6
img_history_interval: 20
action_chunk_size: 25
downsample_rate: 1
act_type: relative_chunk_ee_RT
umi_coord_frame: true
umi_gripper_space: false
use_video_encoder: true
```

## 数据划分限制

本次训练使用了全部官方轨迹。训练过程中的 validation 来自训练 dataloader 抽样，并非严格
独立留出集。仓库会将其标注为 offline proxy validation；真正效果通过独立 seed 的闭环
RoboDojo/X-Eval 评测判断。
