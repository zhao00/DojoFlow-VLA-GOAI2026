
训练机器可以通过 `WANDB_MODE=offline` 工作。离线 run 可复制到联网机器后执行
`wandb sync`，但模型权重需单独保存。

## 部署

部署采用 XPolicyLab 已提供的 `policy/Hy_Embodied_05_VLA`。策略端使用 Hy-VLA 运行环境，
环境端使用 RoboDojo/Isaac Sim 环境；跨机器时策略服务器绑定 `0.0.0.0`，环境客户端连接
策略机实际地址。必须使用：

```text
env_cfg_type=arx_x5
action_type=ee
umi_coord_frame=true
```

模型目录和 `norm_stats.pkl` 必须来自同一次导出清单。

## Generalization 冒烟测试

完成 RoboDojo/GOAI assets 安装并替换评测 adapter 后，在 RoboDojo 根目录运行：

```bash
bash scripts/robodojo.sh smoke \
  --dimension generalization \
  --policy-dir XPolicyLab/policy/Hy_Embodied_05_VLA \
  --ckpt HyVLA-GOAI-step-199999 \
  --policy-env uv \
  --eval-env RoboDojo \
  --action-type ee \
  --eval-num 1 \
  --seed 0
```

若从 tmux 或非交互 shell 启动，需确保真正的 Conda 可执行文件对策略服务子进程可见，
例如将 `/opt/conda/bin` 和 `/opt/conda/condabin` 加入 `PATH`。本机部署、版本与远程链路
问题见 `docs/测评部署记录.md`。
